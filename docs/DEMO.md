# 5-Minute Classroom Demo Script

> All data synthetic. Open with the disclaimer — it shows maturity.

## 0:00–0:30 — The problem (1 slide or just say it)
"Patient data is fragmented — labs, vitals over time, notes, images. Single
models look at one slice and can't explain themselves. This system runs five
specialist AI agents over all four modalities, grounds every claim in
retrieved evidence, and flags disagreements for the clinician."

## 0:30–1:30 — Overview tab
- Pick `SYN-SHOW-01` (high-risk patient).
- Point at the three condition rows: cardiac HIGH, diabetes, respiratory.
- Say: "All synthetic — generated by our own simulator, seed 42."

## 1:30–2:30 — Risk & Explainability tab
- Show the attribution bar chart: "The model isn't a black box — systolic BP,
  LDL and age drive this prediction. SHAP when installed, permutation
  importance otherwise."
- Show vital trends: "The temporal model reads *trajectories*, not snapshots
  — rising heart rate across visits."

## 2:30–3:30 — Imaging tab
- Show the synthetic X-ray + heatmap overlay: "DenseNet121 with Grad-CAM —
  the glow shows which lung region drove the finding."
- Flip to a low-risk patient: "No focal abnormality — and watch the fusion
  layer flag a conflict if modalities ever disagree."

## 3:30–4:15 — Evidence tab
- Scroll the citations: "Every claim links to a source snippet — this is RAG
  doing grounded generation, not free hallucination."

## 4:15–4:45 — Agent Trace tab
- Scroll the log: "Five agents, one orchestrator, every step timestamped.
  This is the audit trail a hospital would demand."

## 4:45–5:00 — Final Report + close
- Show the structured report with conflicts and uncertainty sections.
- Close: "Decision *support*, not decision *making* — the report says so on
  every tab. Ablation results are in docs/EVALS.md."

## If something breaks live
- No Ollama? Template summaries kick in automatically — say so, it demos
  graceful degradation.
- No torch? Heuristic vision + trend features run — the UI labels them.
